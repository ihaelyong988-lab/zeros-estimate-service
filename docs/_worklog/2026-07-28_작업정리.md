# 2026-07-28 작업정리

## PHASE O-38 — 사업소개(서비스 소개) 모바일: 한 화면 수납 · 문단 정돈

### 지시 (사용자 캡쳐 + 후속 3회)
1. (캡쳐) `무료` 옆에 `소액 예산 공사`를 배치해 **세로폭 도형을 줄여** 실속 있게 — 하단 `소정 수수료` 카드도 동일. 아래로 쭉 전체 검토.
2. (캡쳐) `이렇게 제공합니다` 문장의 **위·아래 공간이 안 맞음**. 전반적으로 **내용 절반·여백 절반 — 미술품 아님**, 균형감 있게.
3. "내가 제공한 화면만 조정해, 전체 다 조사하지 말고" → **범위 = 사업소개 탭 모바일 화면 단독.**
4. "한 화면에 나올 만큼만 세로폭 균형을 맞추어줘" → 목표를 **스크롤 0**으로 상향.
5. "문단을 깔끔하게 정돈해" → 한글 단어 절단 제거.

### 조치 (app/page.tsx `renderBusinessTab`, components/layout/AppShell.tsx)
1. **배지+제목 한 줄 인라인** — `무료`+`소액 예산 공사` / `소정 수수료`+`일정 금액 초과 공사`. 인덱스 `01/02`는 `ml-auto shrink-0` 우측 유지, 제목 `min-w-0`(truncate 금지).
2. **성장 축 라벨 인라인** — `지금`/`목표` 라벨을 제목과 같은 행. `±5%`는 우측 baseline 유지.
3. **문단 정돈** — 루트 `break-keep`(단어 단위 유지) + 본문 `<p>` `text-pretty`. 고아 줄(`다.` 단독) 소멸.
4. **카드 높이 동일화** — 설명 줄 수 차이로 81.6 vs 104.3 어긋남 → 그리드 `auto-rows-fr` + 카드 `flex flex-col` + 언더라인 `mt-auto pt-1.5 sm:pt-4`(하단 정렬).
5. **2열 전환 `sm:` → `md:`** — 640px에서 인라인 헤더 폭 부족으로 카드2 제목이 2줄(46.8px)로 깨짐 → `grid-cols-1 md:grid-cols-2`.
6. **모바일 세로 예산 압축** — 모바일 기본값만 낮추고 `sm:` 이상은 데스크톱 구값 명시 유지(회귀 0). 루트 `py-2/gap-2`·본문 `py-2.5/gap-2.5`·블록 `gap-2.5`·카드 `p-2.5`·설명 `leading-snug`·성장축 `gap-0.5`·CTA `gap-2 pb-0`.
7. **셸 하단 죽은 공간 회수** — 하단 탭바는 `fixed`가 아니라 `shrink-0` 플렉스 형제라 클리어런스 불필요한데 `pb-28`(112px)이 깔려 있었음 → **business 탭만** `px-4 py-3`. **다른 탭은 `p-4 pb-28` 불변**(실측 확인).

### 오류 원장 (이번에 겪은 것)
- **`preview_start`가 launch.json을 못 찾음** — 세션 primary cwd(`C:\dev`) 기준으로 탐색. 처방: 루트에 `npm run dev --prefix zerospipe.co.kr` 설정 추가.
