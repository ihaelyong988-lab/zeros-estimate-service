## 4. 라이브 실측으로 확증한 것 (추정 아님)

1. **의뢰 폼이 공사 종류를 한 번도 묻지 않는다.** `RequestWizard.tsx`의 `work_type`·`site_type`·`work_purpose`는 정의(120–122행)와 제출(448–450행) 두 곳에만 등장하고 이를 바꾸는 입력이 없다. 프로덕션 DB의 실제 접수 2건이 전부 `배관공사/공장`으로 저장돼 있어 코드 판독과 데이터가 일치한다.
2. **공개 실적 101건 중 99건이 `est-test-*` 시드**다. 같은 방문자가 사업소개에서 `246건`(`lib/constants/trust.ts:20` 하드코딩), 실적 집계표에서 `101건`(DB 실측)을 본다.
3. **env 4종 등록이 보안 결함 2건의 방아쇠다.** 관리자 로그인에 시도 제한이 없고(`app/api/admin/login/route.ts:34` — 다른 라우트는 `rateLimit`을 쓰는데 여기만 없다), `createEstimate`가 클라이언트가 보낸 `submitted_files` 경로를 무검증 저장해 `/api/files/sign`의 소유권 판정을 통과시킨다. 지금은 로그인 503·고객 세션 토큰 발급 불가로 미발동이다. **지난 차수 P2-2와 같은 "키 등록 전 선행 필수" 구조다.**
4. **관리자 세션 8시간 만료 시 접수목록이 크래시**한다(`EstimateList.tsx:218`). 만료 시 PII 제거 행이 내려오는데 `est.customer_name.toLowerCase()`가 그대로 실행된다. 관리자 토큰 TTL이 8시간(`lib/otp/token.ts:108`)이라 매일 재현된다.
5. **모바일 홈 셸 배경이 `rgb(4,27,51)` = `#041B33`** — AGENTS §10-A 공통 1항이 문자열째 금지한 값이다. `isMobileLanding`일 때만 적용돼 다른 탭에서는 흰 배경이라 눈에 띄지 않았다.
6. **`ui-quality-gate`는 변경된 `.tsx`만 채점**한다(클린 트리에서 `--check` → "변경된 UI 없음"). 기존 접근성 부채는 어떤 마감에서도 걸리지 않는다.
